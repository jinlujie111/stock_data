## 1. 需求背景与目标

### 1.1 背景

在需求1「主线板块确认」的五维评分框架基础上，业务需要一套**更细粒度、可参数化、可信号化**的量化主线识别体系。该体系将资金、趋势、情绪、龙头、景气拆分为 **F / T / E / L / P** 五大主因子，通过截面标准化合成 **MainScore**，并输出 **Top3 主线池** 及 **启动 / 退潮** 布尔信号，支撑每日收盘后的投研决策与策略因子输入。

### 1.2 目标

- 对每个行业（申万一级/二级，实施时选定一种）计算五大主因子及 **MainScore**（0–100 标准化后加权）。
- 每日输出 **Top3 主线行业** 及排名明细。
- 对每条主线判断 **启动信号**、**退潮信号**（多条件 AND，阈值可配置）。
- 支持因子雷达图等可视化下钻（产品化阶段）。
- 权重、阈值集中在 **参数配置表**，便于回测调参，无需改代码。

### 1.3 与需求1的关系

| 维度 | 需求1（主线板块确认） | 需求3（量化主线板块） |
|------|----------------------|----------------------|
| 评分维度 | 资金/趋势/热度/景气/扩散（五维） | F/T/E/L/P（五主因子，子因子更细） |
| 输出 | 全市场排名 + 等级（超级主线等） | **Top3 主线池** + 启动/退潮信号 |
| 龙头 | 热度维度中的「龙头带动性」 | 独立 **L（龙头强度）** 主因子 |
| 参数化 | 权重相对固定 | **05_参数配置** 可调权重与阈值 |
| 工作流 | 榜单 + 三阶段 | 榜单 + **布尔信号** + 雷达图 |

需求3可与需求1**并行建设**：ODS 层复用同一批明细表；评分引擎可独立模块或后续合并为统一「主线服务」。

### 1.4 非目标（本期）

- 不提供自动下单、仓位管理。
- Policy（政策热度）首期可用人工打分或简化规则，NLP 抓新闻为进阶。
- 不提供实时盘中秒级刷新（默认 **T 日收盘后** 日批）。

## 3. 核心业务逻辑

### 3.1 五大主因子（FTELP）

| 主因子 | 含义 | 合成公式（子因子权重） |
|--------|------|------------------------|
| **F** 资金强度 | 资金是否持续聚焦该行业 | F = 0.4A + 0.3V + 0.2ETF + 0.1H |
| **T** 趋势强度 | 是否处于相对强势趋势 | T = 0.4RS + 0.3N + 0.2R + 0.1M |
| **E** 情绪扩散 | 赚钱效应是否在板块内扩散 | E = 0.35Z + 0.25J + 0.2B + 0.2U |
| **L** 龙头强度 | 龙头是否引领板块 | L = 0.5LR + 0.3LC + 0.2LP |
| **P** 产业景气 | 基本面与预期是否支撑 | P = 0.5Earnings + 0.3Policy + 0.2Forecast |

各子因子需先按行业截面 **标准化到 0–100**（建议百分位排名），再按上表权重合成主因子；主因子再次标准化后参与 MainScore。

### 3.2 子因子定义（业务口径）

#### F — 资金强度

| 子因子 | 定义 | 数据来源建议 |
|--------|------|----------------|
| **A** 成交额占比 | 行业当日成交额 / 全 A 成交额 | Wind / Tushare / 聚宽 |
| **V** 成交额增速 | MA5(行业成交额) / MA20(行业成交额) | 滚动计算 |
| **ETF** ETF 净流入强度 | 行业相关 ETF 近 5 日净流入 / ETF 总规模 | 行业–ETF 映射表 + ETF 资金流 |
| **H** 换手活跃度 | 行业平均换手率 / 全市场平均换手率 | 剔除新股/ST |

#### T — 趋势强度

| 子因子 | 定义 | 说明 |
|--------|------|------|
| **RS** 相对强度 | 行业 20 日收益率 / 沪深300（或全 A）20 日收益率 | >1 表示跑赢 |
| **N** 创新高比例 | 行业内近 1 年新高个股数 / 行业总股数 | 趋势广度 |
| **R** 回撤修复速度 | 最近一次回撤天数 / 修复至前高天数 | 越小越好，标准化时取倒数或反向分位 |
| **M** 均线斜率 | 对 MA30 做线性回归斜率（如 SLOPE） | 趋势方向与力度 |

#### E — 情绪扩散

| 子因子 | 定义 | 说明 |
|--------|------|------|
| **Z** 涨停扩散率 | 行业涨停数 / 行业总股数 | |
| **J** 晋级率 | 昨日涨停今日继续涨停数 / 昨日涨停总数 | 连板情绪延续 |
| **B** 炸板率反向 | 1 −（炸板数 / 触板数） | 炸板越少越好 |
| **U** 上涨扩散 | 行业上涨个股数 / 总股数 | |

#### L — 龙头强度

| 子因子 | 定义 | 说明 |
|--------|------|------|
| **LR** 龙头超额收益 | 龙头股 20 日收益 − 沪深300同期收益 | 龙头需先定义（见 4.2） |
| **LC** 连板高度 | 行业内最高连板数 | |
| **LP** 龙头溢价 | 龙头股次日平均开盘/收盘涨幅 | 需历史统计，可二期 |

#### P — 产业景气

| 子因子 | 定义 | 实操建议 |
|--------|------|----------|
| **Earnings** | 行业一致预期净利润增速 | `dwm_sw_industry_prosperity_di`（申万）或 `dwm_dc_*` / `dwm_ths_*` prosperity 的 `earnings_yoy`；无 Wind 时用成分财报同比 |
| **Policy** | 政策热度 | `dwm_*_industry_prosperity_di`.`policy_score`（当前占位 0）；人工/NLP 进阶 |
| **Forecast** | 机构上调评级比例 / 行业研报数量月环比 | 景气 DWM 的 `upgrade_ratio`、`report_cnt_mom`、`forecast_rev_pct` |

### 3.3 MainScore（核心总分）

```
MainScore = wF×F_std + wT×T_std + wE×E_std + wL×L_std + wP×P_std
```

- `F_std` … `P_std`：五大主因子经截面标准化后的 0–100 分值。
- `wF` … `wP`：来自 **05_参数配置**（Excel 示例可为等权或业务给定，如各 0.2；亦常见 F/T 加重如 0.3/0.3/0.15/0.15/0.1，以配置表为准）。
- 支持对 MainScore 做 **3/5/10 日滚动均分**（与需求1一致，降噪）。

### 3.4 实战信号（04_信号判断）

信号为 **布尔值**，条件为 **AND**（全部满足才触发）。阈值存于参数配置表。

#### 主线启动

| 条件 | 说明（Excel 原型） |
|------|-------------------|
| RS > 1.2 | 相对强度显著跑赢 |
| A 连续 3 日上升 | 成交额占比趋势向上 |
| Z > 1.5 × 全市场平均 Z | 涨停扩散显著高于市场 |
| 龙头创新高 | 板块龙头创阶段/年内新高 |
| R ≤ 3 | 回撤在 3 日内修复（修复快） |

#### 主线退潮

| 条件 | 说明（Excel 原型） |
|------|-------------------|
| RS < 0.9 | 相对强度走弱 |
| A 连续 2 日下降 | 资金占比回落 |
| 龙头出现「A 杀」 | 单日跌幅 ≥ 7%（可配置） |
| B（炸板率）> 40% | 情绪恶化（注意：B 为炸板率反向子因子时，退潮规则应对原始炸板率定义一致） |

未触发启动且未触发退潮时，信号状态为 **观察** 或空。

### 3.5 每日输出物

| 输出 | 说明 |
|------|------|
| **Top3 主线行业** | 按 MainScore（或 MA5 MainScore）降序取前 3 |
| **启动 / 退潮标记** | 每条 Top3 或全市场行业均可带 `signal_start`、`signal_exit` |
| **五因子雷达图** | F/T/E/L/P 五轴，供前端展示（数据 API 提供五维分值即可） |
| **因子明细** | 可选下钻至子因子原始值与标准化分 |

**榜单示例字段**

| 字段 | 说明 |
|------|------|
| rank | 排名（1–3 或扩展 TopN） |
| industry_code / industry_name | 行业标识 |
| main_score | MainScore |
| main_score_ma5 | 5 日均分（可选） |
| score_f / score_t / score_e / score_l / score_p | 五主因子标准化分 |
| signal_start | 是否触发启动（0/1） |
| signal_exit | 是否触发退潮（0/1） |
| rs_20d | RS 原始值或比值 |
| amount_ratio | A 成交额占比 |
| limit_up_ratio | Z 涨停扩散率 |

## 4. 功能需求

### 4.1 Excel 工作流对标（产品逻辑）

系统逻辑与 Excel 五层工作表一一对应：

| 工作表 | 功能 |
|--------|------|
| 01_原始数据 | 每日各行业原始指标（申万一级/二级） |
| 02_因子计算 | 计算 F/T/E/L/P 各子因子及主因子 |
| 03_MainScore | 汇总 MainScore、排序、生成 Top3 |
| 04_信号判断 | 启动 / 退潮布尔信号 |
| 05_参数配置 | 权重、阈值（RS>1.2、Z 倍数等） |

### 4.2 龙头识别规则（L 因子前置）

- 默认：行业内 **20 日涨幅最高** 且 **成交额排名前 N**（如 Top3）的标的作为龙头候选；或沿用需求2「主线板块龙头」榜单。
- 连板高度 LC 取自 `limit_up_di` 行业内最大值。
- 「龙头创新高」「A 杀」依赖龙头标的日线序列。

### 4.3 行业–ETF 映射

- 维护 **`dim_industry_etf_map`**（`run_dim_industry_etf_map`；如半导体 → 芯片 ETF 用 `map_type=manual`），用于 ETF 子因子。
- 映射变更需记录生效日，避免回测断层。

### 4.4 数据接入优先级

| 优先级 | 数据 | 用途 |
|--------|------|------|
| S | 行业指数、行业成交额、成分股、个股日线 | A、V、H、RS、N、U |
| S | 涨停/炸板、连板 | Z、J、B、LC |
| A | ETF 资金流、行业–ETF 映射 | ETF 子因子 |
| A | 财务/一致预期、机构评级 | Earnings、Forecast（**景气 DWM 已 ETL**，见需求1 技术文档 §3.5） |
| B | 政策 NLP、新闻热度 | Policy |

| 数据项 | 免费/低成本工具 |
|--------|----------------|
| 行业行情、成分股 | Tushare Pro |
| 涨停/炸板 | Tushare `limit_list` 或 AKShare |
| ETF 资金流 | 东方财富 / 集思录（爬虫） |
| 一致预期 | 无 Wind 时用近 4 季度净利润增速替代 |

### 4.5 接口与展示（建议）

- `GET /api/v1/quant-mainline/top?trade_date=&top=3` — Top3 + 信号 + 五维分
- `GET /api/v1/quant-mainline/signals?trade_date=` — 全市场启动/退潮列表
- `GET /api/v1/quant-mainline/{industry_code}/history` — MainScore 与因子历史曲线
- `GET /api/v1/quant-mainline/config` — 当前生效参数（只读或管理端可写）

## 5. 业务规则与约束

1. **交易日对齐**：仅交易日计算；非交易日展示最近交易日结果。
2. **行业分类**：申万一级或二级择一，与 `industry_member_di` 版本一致。
3. **缺失数据**：子因子缺失时该主因子内降权或标空，禁止静默填 0；MainScore 计算需记录 `data_quality` 标志。
4. **可解释性**：MainScore 可下钻至 F/T/E/L/P 及 A/V/Z 等原始因子。
5. **参数变更**：05 参数表变更需版本号 + 生效日，历史分数支持按版本重算（可选）。
6. **性能**：全市场行业日批目标 **分钟级**（行业数约 30–100）。

| AC-5 | 启动/退潮信号与 Excel 条件一致（阈值可配置） |
| AC-6 | 参数配置表修改后，下一交易日计算生效且可追溯版本 |
| AC-7 | 提供技术文档约定的落库表或 API |
| AC-8 | 典型历史板块（如 CPO、创新药）信号可人工复核 |
