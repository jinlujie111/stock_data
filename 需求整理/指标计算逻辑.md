### 0.1 截面归一化方法对照

## 1. 需求1 — 主线板块确认

**落库**：`dwm_dc_industry_*_di` → `dws_dc_industry_mainline_score_di` → `dws_dc_industry_mainline_monitor_di`  
**脚本**：`dw-dwm/pro_dwm_dc_industry_*_di.sh`、`dw-dws/pro_dws_dc_industry_mainline_*_di.sh`

### 1.1 DWM 原始因子

#### 1.1.1 资金强度 `dwm_dc_industry_fund_flow_di`

| 指标 | 计算逻辑 | 来源 |
|------|----------|------|
| 主力净流入 `net_amount` | ODS 透传 | `ods_industry_fund_flow_di` |
| 资金流入强度 `fund_inflow_strength` | `net_amount / board_amount` | 分母 `ods_dc_daily_di.amount` |
| 连续净流入天数 `net_inflow_days` | 120 自然日窗口内，自当前日向前：遇 `net_amount≤0` 则 streak 归零 | 同上 |
| 近 5 日平均净流入 `net_amount_5d_avg` | 窗口 `ROWS BETWEEN 5 PRECEDING AND 1 PRECEDING` 的 AVG | 同上 |
| 资金加速度 `fund_accel` | `net_amount - net_amount_5d_avg` | 同上 |
| 超大单占主力比 `elg_net_ratio` | `buy_elg_amount / net_amount` | 同上 |

#### 1.1.2 趋势强度 `dwm_dc_industry_trend_strength_di`

| 指标 | 计算逻辑 | 来源 |
|------|----------|------|
| RS 5 日 `rs_5d` | 板块 5 日涨跌幅之和 − 沪深300 5 日涨跌幅之和 | `ods_dc_daily_di` + `ods_index_daily_di`(000300.SH) |
| RS 20 日 `rs_20d` | 同上，20 日 | 同上 |
| 均线多头 `ma_bullish` | `MA5 > MA10 > MA20` → 1，否则 0 | `ods_dc_daily_di` |
| 60 日新高 `is_new_high_60d` | `close >= high_60d × 0.999` → 1 | 同上 |
| 回撤 `drawdown_pct` | `(close - high_60d) / high_60d × 100` | 同上 |
| 回撤修复天数 `recovery_days` | 若 `drawdown_pct > -3%` → 0；否则距上次 60 日高点的交易日数 | 同上 |
| RS 排名 `rs_rank` | 同 `content_type` 内按 `rs_5d` 降序 ROW_NUMBER | — |

#### 1.1.3 市场热度 `dwm_dc_industry_market_heat_di`

| 指标 | 计算逻辑 | 来源 |
|------|----------|------|
| 成交额占比 `amount_ratio` | 板块成交额 / 全 A 成交额 | `ods_dc_daily_di`、`ods_stock_detail_di` |
| 涨停扩散率 `limit_up_ratio` | 涨停家数(U) / 成分数 | `ods_limit_list_di`、`ods_dc_member_di` |
| 20cm 涨停占比 `limit_up_20cm_ratio` | 创业板/科创板涨停 / 成分数 | 同上 |
| 上涨家数占比 `up_ratio` | 上涨家数 / 成分数 | `ods_stock_detail_di` |
| 热度排名 `heat_rank` | 同类型内 `amount_ratio` 排名 | — |
| 东财热榜 `dc_hot_rank` 等 | **透传，不参与主线评分** | `ods_dc_hot_di` |

#### 1.1.4 扩散效应 `dwm_dc_industry_diffusion_di`

| 指标 | 计算逻辑 | 来源 |
|------|----------|------|
| 上涨/下跌/平盘占比 | 各计数 / 成分数 | 成分 + `ods_stock_detail_di` |
| 涨停扩散率 | 同 1.1.3 | `ods_limit_list_di` |
| 炸板率 `blast_ratio` | `Z 类型数 / (涨停数 + 炸板数)` | 同上 |
| 封板成功率 | `1 - blast_ratio` | 同上 |
| 晋级率 `continue_limit_ratio` | 今日连板数 / 昨日涨停数 | 同上 |
| 最高连板 `max_limit_times` | 成分内 MAX(limit_times) | 同上 |
| 相对市场上涨 `up_vs_market` | `up_ratio / market_advance_ratio` | `dwm_market_breadth_di` |

#### 1.1.5 产业景气 `dwm_dc_industry_prosperity_di`

| 指标 | 计算逻辑 | 来源 |
|------|----------|------|
| 业绩增速 `earnings_yoy` | 成分股 `netprofit_yoy` 等权均值（最新 `ann_date≤trade_date`） | `ods_fina_indicator` |
| 单季净利增速 `earnings_q_yoy` | 成分 `q_profit_yoy` 均值 | 同上 |
| ROE 均值 `roe_avg` | 成分 `roe` 均值 | 同上 |
| 预测净利润 `forecast_np_avg` | 近 30 自然日研报 `np` 均值 | `ods_report_rc_di` |
| 预测修正 `forecast_rev_pct` | `(近30日np均值 − 前30日np均值) / |前30日| × 100` | 同上 |
| 上调评级占比 `upgrade_ratio` | 买入/增持类评级数 / 有评级研报数（30 日） | 同上 |
| 研报条数环比 `report_cnt_mom` | 30 日条数环比 | 同上 |
| 政策热度 `policy_score` | **默认 0（占位）** | — |

### 1.2 DWS 五维主线评分 `dws_dc_industry_mainline_score_di`

**步骤**：

1. 各子因子 → `100 × PERCENT_RANK()`（`recovery_days` **降序**排名，越小越好）
2. 维度内子因子加权 → `score_fund / score_trend / score_heat / score_prosperity / score_diffusion`
3. 五维加权 → `total_score`
4. 滚动均分 → `total_score_ma3/ma5/ma10`

**维度权重（默认）**：

| 维度 | 权重 | 子因子（权重） |
|------|------|----------------|
| 资金 `score_fund` | 35% | 流入强度 40%、连续净流入 30%、加速度 20%、超大单占比 10% |
| 趋势 `score_trend` | 25% | RS5d 40%、均线多头 30%、60 日新高 20%、回撤修复 10% |
| 热度 `score_heat` | 15% | 成交额占比 50%、涨停扩散 30%、换手率 20% |
| 景气 `score_prosperity` | 15% | 业绩增速 50%、预期修正 30%、上调评级 20% |
| 扩散 `score_diffusion` | 10% | 上涨占比 50%、20cm 涨停 30%、晋级率 20% |

**等级 `mainline_level`**（按 `total_score`）：

| 分数 | 等级 |
|------|------|
| > 85 | 超级主线 |
| ≥ 70 | 主线 |
| ≥ 60 | 轮动热点 |
| 其他 | 跟风 |

---

### 1.3 主线监控 `dws_dc_industry_mainline_monitor_di`

| 字段 | 逻辑 |
|------|------|
| `main_score` | 优先 `total_score_ma5`，不足 5 日则 `total_score` |
| `mainline_stage` | 见下表（优先级：机构化 > 板块爆发 > 资金试探 > 观察） |

| 阶段 | 判定（概要） |
|------|--------------|
| 机构化 | ETF 5 日份额净增 + `main_score≥70` + 连续净流入≥3 + `rs_5d>0` |
| 板块爆发 | `rs_5d>0` + 涨停扩散率≥同类型 P80 + 连续净流入≥2 |
| 资金试探 | `fund_accel>0` + 连续净流入≥1 |
| 观察 | 以上均不满足 |

## 2. 需求2 — 板块龙头股

**落库**：`dwm_sector_stock_dragon_score_di`、`dwm_sector_dragon_summary_di`  
**脚本**：`etl/sector_dragon/score_mvp.py`、`dw-dwm/pro_dwm_sector_dragon_score.sh`

**范围**：东财行业 + 概念各板块内成分股截面；成分 `< min_constituents`（默认 3）的板块跳过。

### 2.1 百分位（板块内）

```
percentile(v) = count(成分股 x 满足 x ≤ v) / n × 100
```

### 2.2 四维得分

| 维度 | 字段 | 计算逻辑 | 默认合成权重 |
|------|------|----------|--------------|
| 产业龙头 | `score_industry` | 百分位后加权：归母净利 YoY 35%、单季净利 YoY 25%、ROE 25%、上调评级 7.5%、预测修正 7.5% | — |
| 资金龙头 | `score_fund` | 近 20 交易日 `net_mf_amount` 之和的百分位 | — |
| 趋势龙头 | `score_trend` | `(rs_score + amount_pct) / 2`（缺一则取单边） | — |
| 机构龙头 | `score_inst` | 近 30 日研报条数百分位 | — |

**RS 子分（用于趋势）**：

```
rs_raw = 个股60日复合收益 / 板块60日复合收益
rs_score = 90 × min(max(rs_raw, 0), rs_cap) / rs_cap    # 默认 rs_cap=3
```

复合收益：`EXP(SUM(LN(1 + pct/100))) - 1`

### 2.3 综合龙头分 `score_composite`

| 因子 | 默认权重 |
|------|----------|
| 资金百分位 | 40% |
| RS 分 | 30% |
| 成交额百分位 | 20% |
| 市值百分位 | 10% |

各维度最高分者标记 `is_*_leader=1`；综合最高 `is_composite_leader=1`。

## 3. 需求3 — 量化主线（FTELP）

**落库**：`dws_dc_industry_quant_mainline_di`、`dws_dc_industry_quant_mainline_signal_di`  
**脚本**：`etl/quant_mainline/batch.py`、`dw-dws/pro_dws_dc_industry_quant_mainline_di.sh`

### 3.1 计算流水线

1. 读取 DWM / ODS 原始值  
2. 子因子 → 截面百分位 0–100（缺失 → 50）  
3. 子因子加权 → F/T/E/L/P 五维分  
4. 五维分再次百分位  
5. `main_score = Σ(维度分 × 维度权重)`，默认各 **20%**  
6. `rank_score = main_score_ma{ma_window_rank}`，默认 MA5  
7. 各 `content_type` TopN（默认 10）→ `is_top3` 标记

### 3.2 FTELP 子因子

| 维度 | 代码 | 子因子 | 原始来源 | 子权重 |
|------|------|--------|----------|--------|
| **F 资金** | score_f | A 成交额占比 | `dwm_dc_industry_market_heat_di.amount_ratio` | 40% |
| | | V 量能比 | `MA5(amount)/MA20(amount)`（`ods_dc_daily_di`） | 30% |
| | | ETF | 固定 50（MVP 占位） | 20% |
| | | H 换手率 | `turnover_rate` | 10% |
| **T 趋势** | score_t | RS | `(1+板块20日收益)/(1+沪深300 20日收益)` | 40% |
| | | N 60日新高 | `is_new_high_60d` | 30% |
| | | R 回撤修复 | `recovery_days`（越小越好） | 20% |
| | | M 均线多头 | `ma_bullish` | 10% |
| **E 情绪** | score_e | Z 涨停扩散 | `limit_up_ratio` | 35% |
| | | J 晋级率 | `continue_limit_ratio` | 25% |
| | | B 封板成功率 | `1 - blast_ratio` | 20% |
| | | U 上涨占比 | `up_ratio` | 20% |
| **L 龙头** | score_l | LR 龙头超额 | `(龙头20日收益 − 板块20日收益)×100` | 50% |
| | | LC 最高连板 | `max_limit_times` | 30% |
| | | LP 龙头涨停 | 固定 50（MVP） | 20% |
| **P 景气** | score_p | Earnings | `earnings_yoy` | 50% |
| | | Policy | `policy_score`（默认 0） | 30% |
| | | Forecast | `forecast_rev_pct` | 20% |

权重可配：`dwm_dc_mainline_config` 中 `w_f/t/e/l/p` 与 `*_weights` JSON。

### 3.3 启动 / 退潮信号

配置键 `signal_thresholds`（默认值见 `etl/quant_mainline/db_util.py`）。

**启动**（以下 **全部** 满足，`signal_start=1`）：

| 条件 | 默认阈值 |
|------|----------|
| RS 比值 | > 1.2 |
| 成交额占比 | 连升 3 日 |
| 涨停扩散 | > 全市场均值 × 1.5 |
| 创新高 | 板块/趋势创新高 |
| 回撤修复 | ≤ 3 日 |

**退潮**（以下 **任一** 满足，`signal_exit=1`）：

| 条件 | 默认阈值 |
|------|----------|
| RS | < 0.9 |
| 成交额占比 | 连降 2 日 |
| 龙头跌幅 | ≤ -7% |
| 炸板率 | > 0.4 |

否则 `signal_status = 观察`。

## 4. 需求4 — AI 板块成分股识别

**落库**：`dwm_industry_stock_ai_score_di`、`dwm_industry_stock_core_di`  
**脚本**：`etl/ai_core_pool/batch.py`、`dw-dwm/pro_dwm_ai_core_pool_di.sh`

### 4.1 评分来源

| 模式 | 逻辑 |
|------|------|
| LLM | Prompt 输出 JSON：`industry_match, segment, core_degree, score, reason` |
| 规则引擎（无 Key / `--use-rules`） | 见 4.2 |

**主营相关占比**（规则与后处理共用）：

```
keywords = 赛道名及去后缀关键词
mainbz_related_pct = Σ(匹配关键词的 bz_sales) / Σ(bz_sales) × 100
```

数据来源：`ods_fina_mainbz_di`（按股最新报告期）。

### 4.2 规则引擎 `rule_based_analyze`

| 项 | 分值 |
|----|------|
| 基础分 | 30 |
| 赛道关键词命中 ≥3 / ≥1 | +25 / +12 |
| 主营相关占比 | +min(40, pct×0.8)；pct≥30% 强制 `industry_match=true` |
| 近 90 日有研报 | +8 |
| 有财务概览 | +5 |
| 无公司资料且无主营 | score=15，不匹配 |

分数裁剪至 [0, 100]。

### 4.3 后处理规则 `apply_rules`

| 规则 | 条件 | 结果 |
|------|------|------|
| R-3 | `industry_match=false` | level=C |
| R-2 | score ≤ `reject_score`（默认 20） | 不匹配，level=C |
| R-1 | `mainbz_related_pct < mainbz_min_pct`（默认 10%） | 不匹配，level=C |

**等级映射**：S≥90，A≥80，B≥60，否则 C。

### 4.4 核心池 `build_core_pool`

入池条件：`industry_match=true` 且 score≥`score_threshold`（60）且 score>`reject_score` 且 level∈{S,A,B}。

```
weight = 个股score / 同赛道入池score之和
```

## 5. 需求5 — 板块量价关系（VPA）

**落库**：`dwm_stock_vp_factor_di` → `dwm_industry_vp_agg_di` → `dwm_industry_vp_score_di`  
**脚本**：`etl/volume_price/*`、`dw-dwm/pro_dwm_industry_vp_score.sh`

**默认窗口**：20 交易日（`dwm_vp_config.window_default`）。

### 5.1 个股因子 `dwm_stock_vp_factor_di`

| 指标 | 公式 |
|------|------|
| `vol_ma20` | 20 日成交量均值 |
| `vol_ratio_20` | `vol / vol_ma20` |
| `price_trend_20` | `(close − close_lag20) / close_lag20 × 100` |
| `vol_streak_days` | 连续满足 `vol > vol_ma20` 的天数 |
| `is_breakout_60` | `close ≥ high_60` 且 `vol > vol_ma20 × 1.5` |
| **量价形态** `vp_pattern` | 价涨+量涨→趋势确认；价涨+量缩→缩量上涨；价跌+量涨→出货；否则低迷筑底 |
| **形态分** `vp_pattern_score` | 基础分 90/55/25/50 ± 调整项（涨跌幅、量比） |

来源：`ods_stock_detail_di`、`ods_daily_basic_di`；可选排除 ST。

### 5.2 板块聚合 `dwm_industry_vp_agg_di`

| 指标 | 公式 |
|------|------|
| `avg_pct_chg` | 成分涨跌幅，**流通市值加权**（无市值则等权） |
| `rising_ratio` | 上涨家数 / 有效成分数 |
| `vol_expand_ratio` | `vol_ratio_20 > 1.2` 家数占比 |
| `breakout_ratio` | `is_breakout_60=1` 家数占比 |
| `industry_vol_ratio_20` | 板块总成交额 / 近 20 日板块成交额均值 |
| `amount_streak_days` | 板块成交额连续高于其 MA(window) 的天数 |

过滤：`member_cnt ≥ min_member_cnt`（默认 5）。

### 5.3 行业 VP 分 `dwm_industry_vp_score_di`

同 `content_type` 内，各原始指标 → 百分位子分 → 加权：

| 子分 | 原始指标 | 默认权重 |
|------|----------|----------|
| score_vol | industry_vol_ratio_20 | 30% |
| score_trend | avg_pct_chg | 25% |
| score_continuity | amount_streak_days | 15% |
| score_breadth | rising_ratio | 15% |
| score_breakout | breakout_ratio | 15% |

```
vp_score = Σ(子分 × 权重)
rank_vp = 同类型内 vp_score 降序排名
```

**状态 `vp_status`**（按 vp_score）：

| 分数 | 状态编码 | 中文 |
|------|----------|------|
| ≥ 80 | mainline_burst | 主线爆发 |
| ≥ 60 | trend_up | 趋势上升 |
| ≥ 40 | range_bound | 震荡 |
| ≥ 20 | weak | 弱势 |
| < 20 | ebbing | 退潮 |

**信号 `signal_type`（当前代码 MVP）**：

| vp_status | signal_type |
|-----------|-------------|
| mainline_burst | main_rise（主升） |
| ebbing | ebbing（退潮） |
| 其他 | none |

> 需求文档中的「启动 / 派发」等复杂布尔信号见 [需求5-板块量价关系-需求文档.md](需求5-板块量价关系-需求文档.md) §3.4，**尚未全部落地到 ETL**；以 `industry_score.py` 为准。

## 6. 附录 A — 全市场广度（首页）

**表**：`dwm_market_breadth_di`  
**脚本**：`dw-dwm/pro_dwm_market_breadth_di.sh`

| 指标 | 公式 |
|------|------|
| 上涨家数 / 下跌家数 / 平盘 | 全 A 统计 |
| 涨停 / 跌停家数 | `ods_limit_list_di` |
