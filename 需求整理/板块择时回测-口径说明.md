# 板块择时回测 — 口径说明（2026-08）

## 成交模型（冻结）

| 项 | 约定 |
|----|------|
| 信号确认 | 交易日**收盘**后写入 `signal_type=buy/sell` |
| 买入成交 | **T+1 开盘**（信号日下一交易日 `open`） |
| 卖出成交 | **T+1 开盘** |
| 未平仓 | 回测窗口末日按**收盘**盯市（`is_open=1`） |
| 成本 | `TimingConfig.cost_bps` 单边基点（默认 **3bp**）；买卖各扣一次 |
| 收益率 | `(exit/entry - 1) - 成本`；板块 `total_return` 为逐笔**复利** |
| 成功率 | 盈利已平仓笔数 / 已平仓笔数（不含盯市） |
| 夏普 | 已平仓收益均值 / 标准差（交易级，未年化） |
| Calmar | 总收益 / 最大回撤 |
| 买入持有 | 回测窗口首末收盘比；超额 = 策略 − 买入持有 |

## 抗抖动（信号层，默认）

子分（量价/情绪）日间噪声会带动综合分抖动；软卖出若不过滤，易出现 **T 日买 → T+1 日卖**。

| 参数 | 默认 | 作用 |
|------|------|------|
| `min_hold_days` | **3** | 自买入信号日起未满 N 个交易日：只允许 **止损** 卖出；屏蔽 Score 下穿 / 破 MA20 / 资金连降 / 砸盘 |
| `confirm_days` | **2** | Score 进入买入区 / 卖出区需连续 N 日满足阈值，且此前一日不在该区（真正穿越） |
| `cooldown_days` | **2** | 卖出后冷却 N 个交易日禁止新买入 |

止损（`stop_loss_pct`，默认 8%）**始终立即生效**。

**生效**：改抗抖动参数需重跑 `run_board_timing_batch` 才会改写 `signal_type`。Web「按参数回测」仍只重配已落库信号的成交，但会把上述字段写入 `params_json` 快照便于对照。
