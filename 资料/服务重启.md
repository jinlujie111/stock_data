# 服务重启

> 阿里云服务器常用运维命令（XXL-JOB、MySQL）

---

## 1. XXL-JOB

### 停止服务

```bash
ps -ef | grep xxl_job
# 确认 PID 后 kill（先正常 kill，不要直接 -9）
kill <PID>
```

### 启动 Admin（调度中心）

```bash
cd /opt/xxl-job-deploy
nohup java -Xms128m -Xmx256m -jar xxl-job-admin-3.4.1-SNAPSHOT.jar > admin.log 2>&1 &
```

### 启动 Executor（任务执行器）

```bash
cd /opt/xxl-job/xxl-job-executor-samples/xxl-job-executor-sample-springboot
nohup java -Xms128m -Xmx256m -jar target/xxl-job-executor-sample-springboot-*.jar > executor.log 2>&1 &
```

## 2. MySQL

| 操作 | 命令                             |
|------|--------------------------------|
| 停止 | `sudo systemctl stop mysql`    |
| 启动 | `sudo systemctl restart mysql` |

### systemctl 不可用时（阿里云常见）

```bash
# 1. 找到 mysqld 进程
ps -ef | grep mysqld

# 2. 先正常 kill（不要直接 -9）
kill <PID>
```

示例：

```bash
kill 149738
```
