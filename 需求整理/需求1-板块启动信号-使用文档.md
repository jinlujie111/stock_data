# 需求1：板块启动信号 — 使用文档

> **状态（2026-08）**：人工「启动/观察/放弃」清单**已被板块择时自动化替代**。  
> 买卖事件请以 `/dc/board-timing` 的 `buy`/`sell` 为准（收盘确认、**T+1 开盘成交**），并用回测看收益率/成功率。  
> 下文保留为研究期过滤思路（主线+资金+量价+龙头），勿与择时 `trade_signal` 混称。

> 目标：基于现有报表，判断一个板块是否开始启动，以及是否持续有增量资金流入。  
> 适用页面：`主线板块`、`资金强度`、`行业板块`、`板块量价`、`板块龙头`、**`板块择时`（主入口）**。  
> 输出结论：人工清单为 `启动` / `观察` / `放弃`；系统交易事件为 `buy` / `sell`。

---

## 1. 使用目标

本规则用于解决两个核心问题：

1. 一个板块是否已经开始启动。
2. 启动后是否持续有增量资金流入，而不是单日脉冲或一日游。

判断时不建议只看单个页面，而应串联以下报表：

- `主线板块`
- `资金强度`
- `板块量价`
- `板块龙头`
- `行业板块`（辅助观察当日全景）

---

## 2. 三种结论定义

### 2.1 启动

说明板块刚开始形成合力，已有组织性资金进入，值得重点跟踪。

### 2.2 观察

说明板块出现局部异动，但持续性或一致性还不够，需要继续看 1~3 个交易日。

### 2.3 放弃

说明当前更像脉冲、跟风或退潮，不适合进入重点观察池。

---

## 3. 总体评分框架

建议将判断拆成 4 组，共 100 分：

| 维度 | 分值 | 说明 |
|------|------|------|
| 主线状态 | 30分 | 是否进入主线/爆发阶段 |
| 资金持续性 | 35分 | 是否连续净流入且边际增强 |
| 量价确认 | 20分 | 是否放量、突破、量价共振 |
| 龙头承接 | 15分 | 是否有明确龙头承载板块强度 |

最终按总分给出：

- `>= 75分`：启动
- `55 ~ 74分`：观察
- `< 55分`：放弃

---

## 4. 主线状态评分（30分）

对应页面：`主线板块`

### 4.1 等级 `mainline_level`

| 等级 | 分值 |
|------|------|
| 超级主线 | 15 |
| 主线 | 12 |
| 轮动热点 | 7 |
| 跟风 | 2 |

### 4.2 阶段 `mainline_stage`

| 阶段 | 分值 |
|------|------|
| 机构化 | 15 |
| 板块爆发 | 12 |
| 资金试探 | 10 |
| 观察 | 0 |

### 4.3 主线分趋势

重点观察：

- `main_score`
- `total_score_ma5`
- `total_score_ma10`

加分建议：

| 条件 | 分值 |
|------|------|
| `main_score > ma5 > ma10` | 8 |
| `ma5` 上行但尚未完全发散 | 5 |
| `ma5` 走平 | 2 |
| `ma5` 下行 | 0 |

### 4.4 评分说明

本组总分上限取 30 分，不叠加到超过上限。

## 5. 资金持续性评分（35分）

对应页面：`资金强度`

重点字段：

- `连续净流入天数`
- `资金加速度`
- `资金流入强度`
- `超大单占比`

### 5.1 连续净流入天数 `net_inflow_days`

| 条件 | 分值 |
|------|------|
| `>= 5` | 15 |
| `3 ~ 4` | 12 |
| `2` | 8 |
| `1` | 4 |
| `0` | 0 |

### 5.2 资金加速度 `fund_accel`

| 条件 | 分值 |
|------|------|
| 明显大于 0 | 10 |
| 略大于 0 | 7 |
| 接近 0 | 3 |
| 小于 0 | 0 |

### 5.3 资金流入强度 `fund_inflow_strength`

建议按横向排名判断：

| 排名分位 | 分值 |
|----------|------|
| 前 10% | 10 |
| 前 20% | 8 |
| 前 30% | 6 |
| 前 50% | 3 |
| 其余 | 0 |

### 5.4 超大单占比 `elg_net_ratio`

| 条件 | 分值 |
|------|------|
| 明显为正且不低 | 5 |
| 一般 | 2 |
| 很弱或为负 | 0 |

### 5.5 评分说明

本组总分上限取 35 分。

### 6.2 状态 `vp_status`

| 状态 | 分值 |
|------|------|
| `mainline_burst` | 6 |
| `trend_up` | 5 |
| `range_bound` | 2 |

### 6.3 信号 `signal_type`

| 信号 | 分值 |
|------|------|

### 6.5 评分说明

## 8. 结果判定

### 8.1 启动

总分 `>= 75分`

说明：

- 板块已经形成较明显合力
- 持续资金流入特征较清晰
- 量价结构支持
- 龙头具备承接能力

建议动作：

- 进入重点观察池
- 结合分时、回踩、板块扩散再决定是否参与

### 8.2 观察

总分 `55 ~ 74分`

说明：

- 有部分启动信号
- 但持续性或一致性仍不足
- 可能处于早期，也可能是假动作

建议动作：

- 继续观察 1~3 天
- 看 `连续净流入天数` 是否继续增加
- 看 `资金加速度` 是否转负
- 看 `VP状态/信号` 是否持续改善

### 8.3 放弃

总分 `< 55分`

说明：

- 更像局部脉冲
- 板块、资金、量价、龙头之间未形成共振

建议动作：

- 不纳入重点跟踪
- 若后续重新走强，再重新评估

---

## 9. 硬过滤条件

为避免假信号，建议在总分判断前做两道硬过滤。

### 9.1 降级为“观察”

若满足以下任意一条，则即使总分较高，也先降级为 `观察`：

- `net_inflow_days < 2`
- `fund_accel < 0`
- `mainline_stage = 观察`
- `vp_status = weak` 或 `ebbing`

### 9.2 直接判定“放弃”

若满足以下任意 2 条，则直接判定为 `放弃`：

- `signal_type = distribution` 或 `ebbing`
- 龙头不明确
- 资金加速度连续转负
- `连续净流入天数 = 0/1`
- `VP分 < 60`

---

## 10. 日常使用顺序

建议每日按以下步骤使用：

### 第一步：主线板块初筛

优先挑选：

- `主线 / 超级主线`
- `资金试探 / 板块爆发 / 机构化`
- `main_score`、`ma5`、`ma10` 结构改善的板块

### 第二步：资金强度确认

对候选板块进一步看：

- `连续净流入天数`
- `资金加速度`
- `资金流入强度`
- `超大单占比`

### 第三步：板块量价验证

验证是否存在真实量价共振：

- `VP分` 是否足够高
- 是否出现 `启动 / 主升`
- `行业量比`、`突破占比`、`连续放量` 是否支持

### 第四步：板块龙头确认

验证是否有可交易承接：

- 龙头是否明确
- 龙头是否稳定
- 龙头是否与板块同步增强

### 第五步：形成结论

最终给出三类结论之一：

- `启动`
- `观察`
- `放弃`

## 11. 拆分版规则

根据交易周期不同，建议拆成两套使用方式：

- `短期版`：适合 1~5 个交易日的方向选择与启动确认
- `中期版`：适合 1~8 周的主线跟踪与波段持有

### 11.1 短期版规则

短期版更强调：

- 是否刚开始启动
- 是否有新资金快速进入
- 是否有量价共振
- 是否具备次日到数日的延续性

#### 短期版重点页面

- `主线板块`
- `资金强度`
- `板块量价`
- `板块龙头`

#### 短期版核心字段

- `mainline_stage`
- `net_inflow_days`
- `fund_accel`
- `fund_inflow_strength`
- `vp_score`
- `signal_type`
- `vp_status`
- 龙头是否明确

#### 短期版判定“启动”

以下 5 条满足 3 条即可判为 `短期启动`：

- `mainline_stage` 为 `资金试探` / `板块爆发`
- `net_inflow_days >= 2`
- `fund_accel > 0`
- `vp_score >= 70`
- `signal_type` 为 `launch` / `main_rise`

#### 短期版判定“持续增量资金流入”

以下 4 条满足 3 条即可：

- `net_inflow_days >= 3`
- `fund_accel > 0`
- `fund_inflow_strength` 横向排名靠前
- `amount_streak_days >= 2`

#### 短期版判定“放弃”

以下任意 2 条成立即可：

- `fund_accel < 0`
- `net_inflow_days = 0/1`
- `vp_status = weak/ebbing`
- `signal_type = distribution/ebbing`
- 龙头不清晰或明显掉队

#### 短期版使用特点

优点：

- 反应快
- 更适合抓启动和日内/隔日重点方向
- 对量价变化更敏感

缺点：

- 更容易受到情绪波动干扰
- 对连续性要求较低，容易把部分脉冲行情纳入观察

#### 短期版结论定位

短期版适合：

- 次日方向筛选
- 1~5 天板块跟踪
- 快速确认是否值得重点盯盘

---

### 11.2 中期版规则

中期版更强调：

- 板块是否进入主升段
- 资金是否持续流入而不是单日冲高
- 评分均线是否走强
- 龙头是否持续承接

#### 中期版重点页面

- `主线板块`
- `资金强度`
- `板块龙头`
- `板块量价`

#### 中期版核心字段

- `mainline_level`
- `mainline_stage`
- `main_score`
- `total_score_ma5`
- `total_score_ma10`
- `score_fund`
- `net_inflow_days`
- `fund_accel`
- 龙头稳定性

#### 中期版判定“启动”

以下 5 条满足 3 条即可判为 `中期启动`：

- `mainline_level` 为 `主线` / `超级主线`
- `mainline_stage` 为 `板块爆发` / `机构化`
- `main_score > ma5 > ma10` 或 `ma5` 明显上行
- `net_inflow_days >= 3`
- `fund_accel > 0`

#### 中期版判定“持续增量资金流入”

以下 5 条满足 4 条即可：

- `net_inflow_days >= 3`
- `fund_accel > 0`
- `fund_inflow_strength` 排名靠前
- `main_score_ma5` 持续抬升
- 龙头稳定且与板块同步增强

#### 中期版判定“放弃”

以下任意 2 条成立即可：

- `mainline_stage = 观察`
- `ma5` 走平或拐头下行
- `fund_accel < 0`
- 龙头明显掉队
- `vp_status = ebbing`

#### 中期版使用特点

优点：

- 更能过滤一日游
- 更适合抓主升段和板块轮动主线
- 对持续资金流入识别更稳

缺点：

- 反应会比短期版慢一些
- 不擅长极早期埋伏

#### 中期版结论定位

中期版适合：

- 1~8 周板块波段
- 主线跟踪
- 盘后构建重点板块池

---

### 11.3 短期版与中期版的差异

| 维度 | 短期版 | 中期版 |
|------|--------|--------|
| 适用周期 | 1~5天 | 1~8周 |
| 核心目标 | 抓启动、抓异动方向 | 抓主升、抓持续资金流入 |
| 更关注 | `fund_accel`、`vp_score`、`signal_type` | `main_score_ma5/ma10`、`mainline_level`、龙头稳定性 |
| 优点 | 反应快 | 稳定性更强 |
| 缺点 | 容易受情绪干扰 | 反应偏慢 |
| 更适合 | 短线跟踪 | 中期波段 |

## 12. 使用注意事项

### 12.1 不要只看单日净流入

单日净流入大，只代表当天有人买，不等于板块启动。

### 12.2 不要只看涨幅

启动早期涨幅未必很大，更重要的是：

- 是否开始持续流入
- 量价结构是否同步改善
- 板块内部是否有扩散

### 12.3 必须结合龙头

板块层面再漂亮，如果龙头没有承接，通常持续性较差。

## 13. 后续可系统化方向

当前规则可以人工使用；后续若要系统化，可考虑新增一张结果表，例如：

- `dws_dc_industry_start_signal_di`

建议字段：

- `trade_date`
- `industry_code`
- `industry_name`
- `signal_score`
- `fund_score`
- `vp_score`
- `leader_score`
- `signal_status`（启动/观察/放弃）
- `is_incremental_fund_inflow`

这样系统可每天直接输出“板块启动信号”和“是否持续增量流入”。

---

## 14. 一句话使用原则

先用 `主线板块` 看有没有启动迹象，再用 `资金强度` 看有没有持续增量资金，最后用 `板块量价 + 板块龙头` 验证启动质量。
