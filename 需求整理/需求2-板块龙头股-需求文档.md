# 需求2：板块龙头股 — 需求文档

> 来源：AI 行业分析平台业务需求（板块多维龙头识别）  
> 版本：v1.4  
> 更新日期：2026-06-10

---

## 1. 需求背景与目标

### 1.1 背景

为提升 AI 行业分析平台在 A 股市场**主线识别**与**板块内选股**能力，需在「板块」粒度之下进一步识别**龙头股**。对东财**全行业 + 全概念**板块（`content_type` 为「行业」「概念」）的成分股，构建可动态评估**产业、资金、趋势、机构**四维表现的龙头识别体系，并输出**综合龙头排名**与文字结论，辅助投研决策。

### 1.2 目标

- 对**每个有效板块**内的成分股计算**四维得分**（产业 / 资金 / 趋势 / 机构）及**综合得分**（0–100）。
- 按板块、按维度识别**单项龙头**与**综合龙头**；支持全市场板块榜单与单板块下钻。
- 支持**周度**（综合榜）与**日度/季度**（分维度）差异化更新频率。
- 输出**评分表**与**文字结论**，并支持 Web 展示与周报推送。

### 1.3 与需求1 / 需求3 的关系

| 维度 | 需求1（主线板块确认） | 需求2（板块龙头股） | 需求3（量化主线板块） |
|------|----------------------|---------------------|----------------------|
| 分析对象 | 全行业板块 | **板块内个股** | 全行业板块 |
| 核心问题 | 哪个行业是主线 | 板块内谁是龙头 | 哪 3 个行业是量化主线 |
| 评分维度 | 资金/趋势/热度/景气/扩散 | 产业/资金/趋势/机构 | F/T/E/L/P |
| 典型输出 | 行业排名 + 等级 | **个股四维分 + 综合分 + 龙头标签** | Top3 + 启动/退潮信号 |

需求2与需求1/3 **共用 ODS 与部分 DWM**（个股行情、资金流、财务、研报等）；成分股范围直接取自 **`ods_dc_member_di` / `ods_ths_member_di`**，按 `industry_code` 过滤后做板块内截面排名。

### 1.4 非目标（本期）

- 不提供自动下单、仓位管理。
- 市占率、专利等**外部行业报告**数据在完整版阶段接入，MVP 可用财报代理指标替代。

## 3. 核心业务逻辑

### 3.1 多维龙头定义

系统需支持以下**五类**龙头识别（四类单项 + 一类综合）：

| 龙头类型 | 核心问题 | 更新频率 |
|----------|----------|----------|
| **产业龙头** | 是否为行业最重要的企业（看产业地位，非股价） | 季度 / 半年 |
| **资金龙头** | 近期大资金是否集中买入 | 周度（1~4 周窗口可切换） |
| **趋势龙头** | 股价相对强度是否最强 | 日度 / 周度（易切换） |
| **机构龙头** | 公募基金是否最偏好 | 季度（基于基金季报） |
| **综合龙头** | 四维加权后的总龙头 | 周度 |

单项龙头判定：板块内对应维度得分**排名第一**的个股；综合龙头为综合分排名第一。支持 Top3 展示（产品可选）。

### 3.2 评分指标与权重

各子指标先在**板块内成分股截面**做排名分（0–100，建议百分位排名），再按权重合成维度分。

#### 3.2.1 产业龙头评分（满分 100）

| 子指标 | 权重 | 说明 |
|--------|------|------|
| 市占率 | 40% | 行业收入/出货量占比（完整版接入第三方报告；MVP 可用营收规模代理） |
| 营收规模 | 25% | 最近报告期营业收入 |
| 净利润规模 | 20% | 最近报告期归母净利润 |
| 研发投入 | 15% | 研发费用或研发费用率 |

```
产业分 = 40%×市占率排名分 + 25%×营收排名分 + 20%×利润排名分 + 15%×研发排名分
```

#### 3.2.2 资金龙头评分（满分 100）

| 子指标 | 权重 | 说明 |
|--------|------|------|
| 日主力净流入 | 40% | 近 N 日（默认 20 日）主力净流入累计或均值 |
| 机构增仓 | 30% | 季报口径机构持股变动（完整版） |
| 北向资金流入 | 15% | 北向持股/净流入（完整版） |
| ETF 持仓变化 | 15% | 相关 ETF 申赎对成分股映射（完整版） |

```
资金分 = 40%×资金流入排名分 + 30%×机构增仓排名分 + 15%×北向排名分 + 15%×ETF增持排名分
```

**MVP**：仅实现「主力净流入」子因子，资金分 = 资金流入排名分（或 100% 权重）。

#### 3.2.3 趋势龙头评分（满分 100）

| 子指标 | 权重 | 说明 |
|--------|------|------|
| 5 日涨幅 | 30% | 近 5 交易日涨跌幅 |
| 20 日涨幅 | 40% | 近 20 交易日涨跌幅 |
| 创新高次数 | 20% | 近 60 日创 N 日新高次数 |
| 相对行业超额收益（RS） | 10% | RS = 个股涨幅 / 板块涨幅（板块涨幅为 0 时单独约定） |

```
趋势分 = 30%×5日涨幅排名分 + 40%×20日涨幅排名分 + 20%×创新高排名分 + 10%×RS排名分
```

> 注：原始需求稿中「日涨幅」重复两项，本版按趋势分析惯例修正为 **5 日 / 20 日** 两档涨幅。

#### 3.2.4 机构龙头评分（满分 100）

| 子指标 | 权重 | 说明 |
|--------|------|------|
| 基金持仓市值 | 40% | 公募基金持股总市值（季报） |
| 持仓基金数量 | 30% | 持有该股的基金只数 |
| 研报数量 | 20% | 近 30 / 90 日卖方研报覆盖 |
| 一致预期净利润增速 | 10% | `report_rc` 一致预期增速 |

```
机构分 = 40%×持仓市值排名分 + 30%×持仓基金数排名分 + 20%×研报数排名分 + 10%×预期增速排名分
```

**MVP**：研报数量 + 预期增速（来自已有 `ods_report_rc_di`），基金持仓待季报 ODS 接入后补齐。

#### 3.2.5 综合龙头评分（最终输出）

| 维度 | 权重 |
|------|------|
| 产业 | 20% |
| 资金 | 35% |
| 趋势 | 25% |
| 机构 | 20% |

```
综合分 = 20%×产业分 + 35%×资金分 + 25%×趋势分 + 20%×机构分
```

权重与窗口参数应可配置（见技术文档 `dwm_dc_sector_dragon_config`）。

### 3.3 MVP 简化模型（第一阶段，快速上线）

在完整四维数据未齐备前，采用**四因子模型**，便于数据获取与周度自动化：

```
综合得分 = 0.4×资金流分 + 0.3×RS相对强度分 + 0.2×成交额占比分 + 0.1×市值分
```

| 因子 | 定义 |
|------|------|
| 资金流分 | 20 日主力净流入在板块内排名分 |
| RS 分 | 个股 60 日涨幅 / 板块 60 日涨幅，上限 3.0 映射为 90 分 |
| 成交额占比分 | 个股日均成交额 / 板块总成交额，板块内排名分 |
| 市值分 | 总市值在板块内排名分（避免小票主导） |

**优势**：资金流、行情、市值、板块指数均可通过现有 **Tushare + stock_data ODS** 获取，适合周度自动更新。MVP 输出可仅含「综合分 + 资金/趋势代理」，四维完整分待 Phase 2 切换。

### 3.4 板块范围（行业 + 概念）

| 项 | 约定 |
|----|------|
| **默认范围** | 东财**行业 + 概念**板块全量（`dwm_dc_industry_fund_flow_di` 中 `content_type IN ('行业','概念')` 的 `industry_code`） |
| **可扩展** | `content_type` 含「地域」时一并纳入（与资金强度页筛选一致，非默认） |
| **成分股** | 当日 `ods_dc_member_di`：`ts_code`=板块代码，`con_code`=个股 |
| **批处理** | 每个交易日 × 每个板块独立截面排名，**禁止**只跑单一赛道或单一类型 |
| **最小成分** | 成分股数 &lt; 3 的板块可跳过或标记「样本不足」 |
| **规模预估** | 行业约百级 + 概念约数百级，合计约 **500~800** 个板块（以 ODS 实际为准） |

成分股来源：**仅**东财/同花顺 ODS 官方成分（`ods_dc_member_di` / `ods_ths_member_di`），不做人工维护单板块池。

## 4. 功能需求

### 4.1 数据接入

**S 级（MVP 必须）— 仓库已具备**

| 业务数据 | ODS / DWM 表 | 用途 |
|----------|--------------|------|

| 个股资金流 | `ods_stock_fund_flow_di` | 主力净流入 |
| 财务指标 | `ods_fina_indicator` | 营收、利润、研发费用 |
| 卖方预测/研报 | `ods_report_rc_di` | 研报数、预期增速 |
| 板块日线 | `ods_dc_daily_di` / `ods_ths_daily_di` | 板块涨幅（RS 分母） |
| 板块成分 | `ods_dc_member_di` / `ods_ths_member_di` | 自动扩池候选 |

**A 级（完整版）**

| 业务数据 | 来源 | 状态 |
|----------|------|------|
| 基金持仓明细 | 基金季报 / Wind / Choice | 待 ODS |
| 北向持股 | Tushare `hk_hold` 等 | 待接入 |
| ETF 份额变动 | `ods_etf_share_size_di` + 行业映射 | ODS 已有，个股映射待建 |

| 专利/研发附注 | 公告、企查查 | 待建设 |

### 4.2 计算与排名

1. 取交易日 `T` 下全部目标板块列表（默认 `content_type IN ('行业','概念')`）。
2. 对每个 `industry_code`，从 `ods_dc_member_di` 加载成分股。
3. 按维度计算子指标原始值 → **板块内**排名分（0–100）。
4. 合成四维分与综合分；标记各维度 Top1（及可选 Top3）。
5. 写入 `dwm_sector_stock_dragon_score_di`、`dwm_sector_dragon_summary_di`（按板块一行结论）。
6. MVP 与完整版通过 `score_mode`（`mvp` / `full`）切换。
7. 产业/机构维度可按**季度报告期**缓存；资金/趋势按**日或周**刷新。

字段扩展建议：`ts_code`、`content_type`（行业/概念）、各维度排名、`score_mode`、`as_of_date`（产业/机构数据截止日期）。

### 4.5 接口与展示（建议）

```
GET /api/v1/dragon/boards?trade_date=&content_types=行业,概念
GET /api/v1/dragon/boards/{industry_code}/scores?trade_date=&mode=mvp|full
```

- `leaders`：跨板块龙头速览（可按综合分或资金分排序；默认含行业与概念）

## 5. 业务规则与约束

1. **板块内比较**：所有排名分仅在同一 `industry_code` 成分股截面计算，禁止与全市场混排。
2. **交易日对齐**：资金/趋势以最近交易日计；产业/机构标注数据截止日期。
3. **缺失数据**：子因子缺失时该子因子权重归零并在明细标黄，禁止静默填 0 导致误判。
4. **ST / 停牌**：可配置剔除 ST、长期停牌股。
5. **可解释性**：每条综合分可下钻四维分及原始因子（`detail_json`）。
6. **性能**：行业 + 概念合计约数百个板块 × 每板块数十成分股，日批目标 **60 分钟内**完成（板块级并行，可配置 worker 数）。

## 7. 实施优先级（分阶段）

### 第一阶段：MVP（快速上线，约 2~3 周）

- [ ] MVP 四因子综合分 ETL + 落库（**行业 + 概念板块批处理**）
- [ ] 全市场板块龙头摘要 API + 单板块下钻
- [ ] 资金/趋势单项龙头（由 MVP 因子代理）

### 第二阶段：完整四维（约 4~6 周）

- [ ] 产业分：财报因子全量（市占率先人工表）
- [ ] 资金分：北向、ETF、机构增仓（随 ODS 就绪）
- [ ] 趋势分：创新高、RS 完整子因子
- [ ] 机构分：基金季报持仓 + 研报
- [ ] 五类龙头标签 + 文字结论模板

### 第三阶段：产品化（约 2 周）

- [ ] Excel 导出、历史曲线、周报推送（行业 + 概念摘要）

| 数据类型 | 当前方案（stock_data） | 付费备选 |

| 行情/资金流 | Tushare `daily` / `moneyflow` | iFinD、Choice |
| 板块/成分 | 东财 `dc_*`、同花顺 `ths_*` | 同花顺官方 |
| 财务/研报 | `fina_indicator_vip` / `report_rc` | Wind、iFinD |
