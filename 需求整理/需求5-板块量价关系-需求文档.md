# 需求5：板块量价关系 — 需求文档

> 来源：量价关系分析模块 PRD（Volume-Price Analysis Engine）  
> 版本：v1.0  
> 更新日期：2026-07-02

---

## 1. 需求背景与目标

### 1.1 背景

A 股市场中，价格容易被短期资金推动，**单纯看涨跌无法区分「真假趋势」**；成交量与成交额则更能反映资金真实行为。业务需要一套以 **「量价关系 + 时间结构 + 行业/板块维度」** 为核心的分析能力，用于判断：

- 当前行业/个股处于 **启动、加速还是派发**；
- 上涨是否有 **量能支撑**；
- 哪些板块正在形成 **主线** 或进入 **退潮**。

### 1.2 模块名称

**量价关系分析系统**（Volume-Price Analysis Engine，简称 **VPA**）

### 1.3 核心目标

系统应能稳定回答以下问题：

| 问题 | 输出形态 |
|------|----------|
| 当前行业/股票是启动、加速还是派发？ | 状态标签 + 信号类型 |
| 是否存在主力持续流入/持续放量？ | 连续放量天数、量比、量价配合分类 |
| 当前上涨是否有量支撑？ | 量价配合强度、Volume-Price Score |
| 是否进入主升浪 or 反弹结束？ | 突破信号、20 日趋势强度 |
| 哪些行业正在成为主线？ | 行业量价评分榜、状态分级 |

### 1.4 与需求1 / 2 / 3 / 4 的关系

| 维度 | 需求1 主线板块 | 需求3 量化主线 | **需求5 板块量价** |
|------|----------------|----------------|-------------------|
| 核心问题 | 哪个板块是主线（五维综合） | Top3 + 启动/退潮（FTELP） | **量价是否支撑趋势、资金行为分类** |
| 分析重心 | 资金/趋势/热度/景气/扩散 | 可参数化因子 + 布尔信号 | **量价比、放量结构、广度、突破** |
| 典型输出 | 等级 + 历史曲线 | MainScore + 启动/退潮 | **VP Score(0–100) + 五档状态 + 信号** |
| 与需求2 | 板块内个股龙头 | — | 可输出「是否跟随行业 / 补涨 / 龙头量价」辅助字段 |

| 维度 | 需求2 板块龙头 | **需求5** |
|------|----------------|-----------|
| 对象 | 板块内个股四维分 | 板块/个股 **量价结构** |
| 互补 | 龙头是谁 | 板块趋势是否 **有量确认** |

| 维度 | 需求4 AI 核心池 | **需求5** |
|------|-----------------|-----------|
| 方法 | LLM 产业归属 | **规则量价**（可对接核心池宇宙过滤） |

**定位**：需求5 不替代需求1/3 的「主线综合评分」，而是提供 **「资金行为是否真实」** 的独立视角；可与需求1 榜单 **并列展示** 或作为 **过滤/加权因子**（V2）。

### 1.5 非目标（本期 MVP）

- 不提供自动下单、仓位管理、实盘交易接口。
- 不提供 Tick/分钟级实时量价（默认 **T 日收盘后日批**）。
- 北向/龙虎榜/ETF 资金层、情绪层（涨停连板）、产业景气层归入 **Phase 2/3**（见 §11）。
- 申万/同花顺 **Web 全量展示** 可 Phase 2 接入；MVP 默认 **东财行业 + 概念**。

## 3. 核心业务逻辑

### 3.1 基础量价指标

| 指标 | 字段来源（现有 ODS） | 说明 |
|------|---------------------|------|
| 收盘价 | `ods_stock_detail_di.close` | — |
| 成交量 | `ods_stock_detail_di.vol` | 手 |
| 成交额 | `ods_stock_detail_di.amount` | 千元 |
| 换手率 | `ods_daily_basic_di.turnover_rate` | % |
| 涨跌幅 | `ods_stock_detail_di.pct_chg` | % |

### 3.2 核心量价关系指标

#### （1）量比（Volume Ratio，核心）

```
量比 = 当日成交量 / 过去 N 日平均成交量（默认 N=20）
```

| 区间 | 含义 |
|------|------|
| < 0.8 | 缩量 |
| 0.8 – 1.2 | 正常 |
| 1.2 – 2.0 | 放量 |
| 2.0 – 3.0 | 强放量 |
| > 3.0 | 异常放量 |

#### （2）量价配合强度（Volume-Price Pattern）

基于 **价格方向** 与 **成交量相对 MA20 的变化方向** 分类：

| 价格 | 成交量 | 解释 | 内部编码 |
|------|--------|------|----------|
| ↑ | ↑ | 趋势确认（最强） | `trend_confirm` |
| ↑ | ↓ | 逼空或衰竭 | `weak_rise` |
| ↓ | ↑ | 出货信号 | `distribution` |
| ↓ | ↓ | 低迷/筑底 | `consolidation` |

**Volume-Price Score（个股/行业）**：在分类基础上映射 0–100（`trend_confirm` 最高，`distribution` 最低，可叠加幅度加权）。

#### （3）20 日趋势强度（默认核心周期）

| 指标 | 定义 |
|------|------|
| 20 日量均线比 | `vol / MA20(vol)` |
| 20 日价趋势 | `MA20(close)` 斜率或 N 日涨幅（默认 20 日 pct 累计） |

#### （4）连续放量天数

**连续 N 天**满足 `volume > MA20(volume)`：

| 天数 | 含义 |
|------|------|
| 1–2 | 异动 |
| 3–5 | 初期趋势 |
| 6–10 | 主升确认 |
| > 10 | 强趋势主线 |

#### （5）突破量价信号

**强趋势启动**（个股）：

```
close >= MAX(close, 过去 60 交易日)  AND  volume > MA20(volume) × 1.5
```

行业级：成分股中满足突破条件的 **家数占比** 或 **市值加权占比**。

### 3.3 多周期设计（必须支持）

| 周期（交易日） | 用途 | MVP |
|----------------|------|-----|
| 3 | 捕捉启动 | 可选 |
| 5 | 短线趋势 | 可选 |
| 10 | 短中趋势 | 可选 |
| **20** | **主力趋势（默认）** | **必做** |
| 60 | 中期趋势、突破窗口 | 必做 |
| 120 | 大趋势 | Phase 2 |

**产品默认展示周期：20 日**；API 支持 `window=20` 参数切换。

### 3.4 行业级量价分析（重点）

#### 3.4.1 行业聚合指标

对板块内成分股聚合（**默认市值加权**，可配置等权）：

| 指标 | 计算方式 |
|------|----------|
| 行业成交额 | `Σ amount`（或 `Σ vol × close` 近似） |
| 行业涨跌幅 | 市值加权平均 `pct_chg` |
| 行业量比 | 行业总成交额 / 行业 20 日平均总成交额 |
| 上涨家数占比 | `上涨家数 / 成分总数` |
| 放量比例 | `量比>1.2 家数 / 成分总数` |
| 突破比例 | 满足 §3.2(5) 家数 / 成分总数 |

#### 3.4.2 行业量价评分 Industry VP Score（0–100）

| 维度 | 权重 | 说明 |
|------|------|------|
| 成交量变化 | 30% | 行业量比、成交额 MA 比 |
| 价格趋势 | 25% | 20 日加权涨跌幅、MA 斜率 |
| 连续放量 | 15% | 行业层面连续放量天数（成交额序列） |
| 上涨家数占比 | 15% | 广度 |
| 突破信号 | 15% | 突破家数占比 |

```
VP_Score = 0.30×VolScore + 0.25×TrendScore + 0.15×ContScore + 0.15×BreadthScore + 0.15×BreakoutScore
```

各子分先 **截面标准化到 0–100**（同一 `trade_date`、同一 `content_type` 下百分位或 Min-Max，技术文档约定）。

#### 3.4.3 行业状态分类

| VP Score | 状态 | 内部编码 |
|----------|------|----------|
| 80 – 100 | 主线爆发 | `mainline_burst` |
| 60 – 80 | 趋势上升 | `trend_up` |
| 40 – 60 | 震荡 | `range_bound` |
| 20 – 40 | 弱势 | `weak` |
| < 20 | 退潮 | `ebbing` |

#### 3.4.4 信号系统（产品层）

| 信号 | 触发条件（示例，可配置） |
|------|-------------------------|
| 主升浪 | VP Score ≥ 80 且 连续放量 ≥ 6 且 上涨占比 ≥ 60% |
| 启动 | 突破比例 ≥ 15% 且 行业量比 ≥ 1.5 且 VP Score 较 5 日前上升 ≥ 10 分 |
| 派发 | 量价配合=`distribution` 且 行业量比 ≥ 1.5 且 价格 5 日涨幅 ≤ 0 |
| 退潮 | VP Score < 20 且 连续 3 日 VP Score 下降 |

## 4. 功能需求

### 4.1 数据加工（ETL）

| 编号 | 功能 | 说明 |
|------|------|------|
| F-1 | 个股量价因子日批 | 量比、MA、量价配合、连续放量、突破标记 |
| F-2 | 行业量价聚合日批 | 东财行业+概念全量板块 |
| F-3 | 行业 VP 评分与状态 | 写评分表 + signal_type |
| F-4 | 多周期参数 | `window` 存配置表或列后缀 `_w20` |
| F-5 | 历史回溯 | 至少保留 120 交易日可查询 |

### 4.2 Web / API 输出

#### 4.2.1 行业排行榜

- 今日 **量价评分 Top N** 行业/概念
- **连续放量** Top 行业（按连续放量天数降序）
- **突破比例** Top 行业

#### 4.2.2 行业趋势卡片

单板块展示：

- 20 日量比、行业涨跌幅
- 连续放量天数
- 上涨家数占比、放量比例
- VP Score + 状态 + 主信号

#### 4.2.3 个股辅助（Phase 2 增强）

- 是否 **跟随行业**（个股量价配合与行业一致）
- 是否 **补涨**（行业 VP 高、个股 VP 低且开始放量）
- 是否 **龙头量价**（对接需求2 龙头 code 列表）

### 4.3 接口建议

```
GET /api/v1/vp/trade-dates
GET /api/v1/vp/industries/rank?trade_date=&content_types=行业,概念&window=20&top=50
GET /api/v1/vp/industries/{industry_code}?trade_date=&window=20
GET /api/v1/vp/industries/{industry_code}/stocks?trade_date=&window=20&limit=100
GET /api/v1/vp/signals?trade_date=&signal_type=mainline_burst|launch|distribution|ebbing
```

Web 页面建议：`/dc/volume-price`（导航归入 **「板块分析」** 或 **「主线决策」**）。

## 5. 业务规则与约束

1. **成分股范围**：与需求2 一致，取自 `ods_dc_member_di`（`ts_code`=板块代码）；成分数 < 5 的板块标记 `sample_insufficient`，不参与排名。
2. **权重**：行业聚合默认 **流通市值加权**（`ods_daily_basic_di.circ_mv` 或 `total_mv`）；缺失时降级等权。
3. **交易日对齐**：所有 MA、连续天数基于 **交易日序列**（`ods_trading_day`），非自然日。
4. **缺失数据**：停牌/无成交个股当日不参与聚合，分母为 **有效成分数**。
5. **ST**：可配置剔除 ST（名称 LIKE 'ST%' 或独立 ST 列表）。
6. **性能**：东财行业+概念约 500–800 板块，日批目标 **30 分钟内**（与龙头批处理同级）。

## 6. 验收标准

| 编号 | 验收项 |
|------|--------|
| AC-1 | 固定测试日 `T`，行业+概念 **≥ 90%** 板块产出 VP Score（其余标记样本不足） |
| AC-2 | 个股量比、量价配合分类与文档公式 **手工抽验 3 股一致** |
| AC-3 | 行业 VP Score 五维权重与 §3.4.2 一致，总分 0–100 |
| AC-4 | 状态五档与分数区间映射正确 |
| AC-5 | API 支持 `trade_date`、`window=20` 查询历史 |
| AC-6 | Web 排行榜、单板块卡片、信号列表可展示 |
| AC-7 | 日批可纳入 `xxl_daily_batch.sh`，ODS 就绪后 exit 0 |
| AC-8 | 技术文档、测试文档、DDL 与代码路径一致 |

## 7. 实施优先级

### Phase 1：MVP（约 2–3 周）

- [ ] 个股量价因子（window=20、60）落库
- [ ] 东财 **行业+概念** 行业聚合 + VP Score
- [ ] 行业排行榜 API + Web 页（Top 榜 + 单板块卡片）
- [ ] 基础信号：`mainline_burst` / `ebbing` 两档

### Phase 2：完整量价（约 3–4 周）

- [ ] 多周期 3/5/10/20/60/120 可切换
- [ ] 四类信号齐全（启动/主升/派发/退潮）
- [ ] 个股下钻页、跟随/补涨标签
- [ ] 申万行业口径并行产出（只写库，Web 可选 Tab）

### Phase 3：增强竞争力（约 4 周+）

- [ ] **资金层**：北向/ETF/龙虎榜加权（见 §11）
- [ ] **情绪层**：涨停数、连板数（可复用 `dwm_dc_industry_diffusion_di`）
- [ ] **产业层**：景气子分接入（`dwm_dc_industry_prosperity_di`）
- [ ] 与需求1 榜单 **联合视图** 或 VP Score 作为主线辅助列

## 8. 升级路线（产品竞争力）

在规则量价核心之上，建议三层叠加：

| 层级 | 内容 | 数据来源建议 |
|------|------|--------------|
| ① 资金层 | 北向、ETF 净流入、龙虎榜 | `ods_hk_hold_di`、ETF 份额、龙虎榜 ODS（待建） |
| ② 情绪层 | 涨停数、连板、炸板率 | `ods_limit_list_di`、`dwm_dc_industry_diffusion_di` |
| ③ 产业层 | 订单、CapEx、景气 | `dwm_dc_industry_prosperity_di`、研报 |

**VPA 核心公式不变**；三层作为 **VP Score 扩展维度** 或 **独立 Tab**（权重可配置）。

## 9. 一句话总结

本需求不是单纯的 K 线/成交量工具，而是：

> **用量价关系识别「主力在买哪个行业、趋势是否有量确认、板块处于生命周期的哪一段」。**
