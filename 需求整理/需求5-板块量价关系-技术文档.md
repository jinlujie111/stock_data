## 4. 核心算法

### 4.1 Step 1：个股基础指标（SQL / Python）

对每只股票按 `ods_trading_day` 排序计算（窗口 W，默认 20）：

```text
vol_maW     = AVG(vol) OVER (PARTITION BY ts_code ORDER BY trade_date ROWS W-1 PRECEDING)
vol_ratio   = vol / NULLIF(vol_maW, 0)
price_maW   = AVG(close) OVER (...)
price_trend = (close - close_lagW) / NULLIF(close_lagW, 0) * 100
high_60     = MAX(close) OVER (PARTITION BY ts_code ORDER BY trade_date ROWS 59 PRECEDING)
is_breakout = close >= high_60 AND vol > vol_maW * 1.5
```

**连续放量天数**：按 ts_code 日序扫描，`vol > vol_maW` 则 streak+1，否则置 0。

### 4.2 Step 2：量价配合分类

```python
price_up = pct_chg > 0  # 或 close > prev_close
vol_up = vol > vol_ma20  # 或 vol_ratio > 1

if price_up and vol_up:
    pattern = "trend_confirm"; base_score = 90
elif price_up and not vol_up:
    pattern = "weak_rise"; base_score = 55
elif not price_up and vol_up:
    pattern = "distribution"; base_score = 25
else:
    pattern = "consolidation"; base_score = 50
```

可按 `|pct_chg|`、`vol_ratio` 微调 base_score ±10（上限 100、下限 0）。

### 4.3 Step 3：行业聚合

对每个 `(trade_date, industry_code)`：

1. 从 `ods_dc_member_di` 取 `member_date` 成分（与需求2 相同 snapshot 逻辑）。
2. JOIN `dwm_stock_vp_factor_di` + `ods_daily_basic_di` 取权重 `w_i = circ_mv_i / Σ circ_mv`。
3. 计算 §3.2 各聚合字段。
4. **行业成交额 MA20**：对 `total_amount` 时间序列做 MA，得 `industry_vol_ratio_20`。

### 4.4 Step 4：行业 VP Score

1. 在同一 `(trade_date, content_type, window)` 截面上，对五个子指标做 **百分位排名分** → `score_vol` … `score_breakout`。
2. 加权求和 → `vp_score`。
3. 按 §3.4.3 映射 `vp_status`。
4. 信号规则（可配置）写 `signal_type`。
5. `RANK() OVER (PARTITION BY trade_date, content_type ORDER BY vp_score DESC)` → `rank_vp`。

### 5.2 func.sh 封装

```bash
run_vp_batch() {
  local dt="${1:-$(get_date)}"
  local content_types="${2:-行业,概念}"
  bash "${DW_ROOT}/dw-dwm/pro_dwm_industry_vp_score.sh" "${dt}" "${content_types}"
}
```

### 5.3 日批顺序（建议插入 xxl_daily_batch.sh）

在 **ODS 个股日线 / daily_basic / dc_member** 就绪之后，**板块龙头批处理之前或之后**均可：

```text
run_data_sync
run_dwm_market_breadth
... 五维 DWM ...
run_vp_batch              # 新增：需求5
run_sector_dragon_batch   # 需求2（可选：龙头量价标签读取 vp 表）
run_mainline_batch
...
run_ods_completeness_monitor
```

| 任务 | 频率 | 依赖 |
|------|------|------|
| ODS daily / daily_basic | 每日 | Tushare |
| dc_member | 每日/按需 | Tushare dc_member |
| **VP 批处理** | **每日** | 上述 ODS + 120 日历史 |

### 5.4 性能建议

- **个股因子**：按 `trade_date` 批量 SQL 窗口函数，或 Python 分 ts_code 块并行；仅计算 **当日有成交** + **member 池内** 股票（MVP 可全市场以简化，约 5000 股 × 120 日窗口）。
- **行业聚合**：按 `industry_code` 并行，worker=8。
- **中间结果**：`dwm_stock_vp_factor_di` 保留 120 日滚动（定期清理更旧分区，Phase 2）。

## 6. API 设计

前缀：`/api/v1/vp`，均需登录 Cookie（与现有 sectors API 一致）。

### GET `/api/v1/vp/trade-dates`

响应：`{ "latest": "2026-06-30", "dates": [...] }`  
数据源：`dwm_industry_vp_score_di` 或 `ods_trading_day`。

### GET `/api/v1/vp/industries/rank`

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| trade_date | string | 最新 | YYYYMMDD |
| content_types | string | 行业,概念 | 逗号分隔 |
| window | int | 20 | 3/5/10/20/60/120 |
| top | int | 50 | 返回条数 |
| sort | string | vp_score | vp_score / vol_ratio / breakout_ratio |

响应示例：

```json
{
  "trade_date": "2026-06-30",
  "window": 20,
  "items": [
    {
      "industry_code": "BK0481.DC",
      "industry_name": "半导体",
      "content_type": "行业",
      "vp_score": 86.5,
      "vp_status": "mainline_burst",
      "signal_type": "main_rise",
      "industry_vol_ratio_20": 1.82,
      "rising_ratio": 0.72,
      "breakout_ratio": 0.18,
      "amount_streak_days": 7,
      "rank_vp": 1
    }
  ]
}
```

### GET `/api/v1/vp/industries/{industry_code}`

单板块 **趋势卡片**：聚合字段 + 五维子分 + 近 N 日 VP Score 序列（历史可选）。

### GET `/api/v1/vp/industries/{industry_code}/stocks`

| 参数 | 说明 |
|------|------|
| sort | vp_pattern_score / vol_ratio_20 / pct_chg |
| limit | 默认 100 |

返回成分股量价因子，供下钻表格。

### GET `/api/v1/vp/signals`

按 `signal_type` 过滤全市场信号列表。
