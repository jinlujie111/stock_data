## 4. 数据完整性测试（P1）

### 4.1 上游 ODS 覆盖

```sql
SET @T = '2026-06-12';

-- A. 板块资金流（东财官方）
SELECT content_type, COUNT(*) AS cnt
FROM ods_industry_fund_flow_di
WHERE trade_date = @T
GROUP BY content_type;
-- 预期：行业约 80~120，概念约 400~500，地域若干；合计与 moneyflow 接口一致

-- B. 东财板块指数 / 日线
SELECT idx_type, COUNT(*) AS cnt
FROM ods_dc_index_di
WHERE trade_date = @T
GROUP BY idx_type;

SELECT idx_type, COUNT(*) AS cnt
FROM ods_dc_daily_di
WHERE trade_date = @T
GROUP BY idx_type;
-- 预期：行业板块、概念板块均有数百条；与 A 的板块集合大体一致

-- C. 个股行情与涨停（趋势/热度/扩散依赖）
SELECT
  (SELECT COUNT(DISTINCT ts_code) FROM ods_stock_detail_di WHERE trade_date = @T) AS daily_cnt,
  (SELECT COUNT(*) FROM ods_limit_list_di WHERE trade_date = @T AND `limit` = 'U') AS limit_up_cnt,
  (SELECT COUNT(DISTINCT ts_code) FROM ods_index_daily_di
   WHERE trade_date = @T AND ts_code IN ('000300.SH','399006.SZ')) AS index_cnt;
-- 预期：daily_cnt > 4000；limit_up_cnt > 0（非极端行情日）

-- D. 财务与研报（景气维）
SELECT
  (SELECT COUNT(*) FROM ods_fina_indicator WHERE end_date >= '20241231') AS fina_cnt,
  (SELECT COUNT(*) FROM ods_report_rc_di WHERE report_date >= DATE_SUB(@T, INTERVAL 30 DAY)) AS rc_30d;
-- 预期：fina_cnt > 0；rc_30d 可为 0（允许景气子因子降权）
```

**通过标准（AC-1）**：S/A 级 ODS 当日有数据；缺失时在测试备注中说明对哪一维造成降权。

### 4.2 五维 DWM 覆盖

### 4.3 DWS 评分与监控覆盖

```sql
SET @T = '2026-06-12';

-- G. 评分表与资金流板块数一致
SELECT
  f.content_type,
  COUNT(DISTINCT f.industry_code) AS fund_boards,
  COUNT(DISTINCT s.industry_code) AS score_boards

  ON s.trade_date = f.trade_date AND s.industry_code = f.industry_code

-- 预期：fund_boards = score_boards

-- H. 监控表
SELECT content_type,
       COUNT(*) AS monitor_cnt,
       SUM(is_top20) AS top20_cnt

WHERE trade_date = @T
GROUP BY content_type;
-- 预期：monitor_cnt = score_boards；top20_cnt = 20（每类型，不足 20 则等于总数）

-- I. 等级分布合理
SELECT content_type, mainline_level, COUNT(*) AS cnt
FROM dws_dc_industry_mainline_score_di
WHERE trade_date = @T
GROUP BY content_type, mainline_level
ORDER BY content_type, mainline_level;
```

### 5.4 三阶段标签（v1 规则）

```sql
SET @T = '2026-06-12';
SET @BOARD = 'BK1036.DC';

-- Q. 阶段与规则对照（机构化本期不产出）
SELECT
  m.industry_name,
  m.mainline_stage,
  m.rs_5d,
  m.limit_up_ratio,
  f.net_inflow_days,
  f.fund_accel,
  CASE
    WHEN m.rs_5d > 0
     AND m.limit_up_ratio IS NOT NULL
     AND 100 * PERCENT_RANK() OVER (PARTITION BY m.content_type ORDER BY m.limit_up_ratio) >= 80

  ON f.trade_date = m.trade_date AND f.industry_code = m.industry_code
WHERE m.trade_date = @T AND m.industry_code = @BOARD;
-- 预期：mainline_stage = expect_stage（或为「板块爆发」当 lur 达 P80）
```

## 6. 公式准确性测试（P3 · 手工验算）

对 **§2.3 行业抽测板** 取 DWS 当日 `rank_no` 第 1、第 10 名各 1 个，在 Excel 或 Python 复算。

### 6.1 标准化与维内加权（与 `pro_dws_dc_industry_mainline_score_di.sh` 对齐）

```text
子因子得分 = 100 × PERCENT_RANK() OVER (PARTITION BY trade_date, content_type ORDER BY 子因子)
  -- recovery_days 为越小越好：ORDER BY recovery_days DESC

资金维度分 score_fund =
  (0.4×pr_fis + 0.3×pr_nid + 0.2×pr_fa + 0.1×pr_elg) / 有效权重和
  子因子：fund_inflow_strength, net_inflow_days, fund_accel, elg_net_ratio

趋势维度分 score_trend =
  (0.4×pr_rs5 + 0.3×pr_mab + 0.2×pr_nh + 0.1×pr_rec) / 有效权重和
  子因子：rs_5d, ma_bullish, is_new_high_60d, recovery_days

热度维度分 score_heat =
  (0.5×pr_amt + 0.3×pr_lur + 0.2×pr_tr) / 有效权重和
  子因子：amount_ratio, limit_up_ratio, turnover_rate

景气维度分 score_prosperity =
  (0.5×pr_ey + 0.3×pr_fr + 0.2×pr_ur) / 有效权重和
  子因子：earnings_yoy, forecast_rev_pct, upgrade_ratio

扩散维度分 score_diffusion =
  (0.5×pr_up + 0.3×pr_20 + 0.2×pr_clr) / 有效权重和
  子因子：up_ratio, limit_up_20cm_ratio, continue_limit_ratio
```

### 6.2 五维总分与等级

```text
total_score =
  (35×score_fund + 25×score_trend + 15×score_heat + 15×score_prosperity + 10×score_diffusion)
  / (35×I_fund + 25×I_trend + 15×I_heat + 15×I_prosperity + 10×I_diffusion)

I_* = 1 当该维 score_* 非 NULL，否则 0（缺失维度降权）

mainline_level:
  total_score > 85  → 超级主线
  total_score >= 70 → 主线
  total_score >= 60 → 轮动热点
  否则              → 跟风
```

### 6.3 DWM 原始因子抽测（资金维示例）

```sql
SET @T = '2026-06-12';
SET @BOARD = 'BK1036.DC';

SELECT
  f.industry_name,
  f.net_amount,
  d.amount AS board_amount,
  f.net_amount / NULLIF(d.amount, 0) AS calc_strength,

  f.fund_accel

  ON d.trade_date = f.trade_date AND d.ts_code = f.industry_code
WHERE f.trade_date = @T AND f.industry_code = @BOARD;
-- 预期：calc_strength 与 fund_inflow_strength 差 < 1e-6
```

### 6.4 Python 复算片段（可选）

```python
# 在服务器：source func.sh 后，用 data_mysql 导出同类型截面，复算 PERCENT_RANK
import pandas as pd
from sqlalchemy import create_engine, text

T, BOARD = "2026-06-12", "BK1036.DC"
# engine = ...  # 只读连接 stock_data

sql = text("""
SELECT industry_code, fund_inflow_strength, net_inflow_days, fund_accel, elg_net_ratio
FROM dwm_dc_industry_fund_flow_di
WHERE trade_date=:t AND content_type='行业'
""")
df = pd.read_sql(sql, engine, params={"t": T})
for col in ["fund_inflow_strength","net_inflow_days","fund_accel","elg_net_ratio"]:
    df[f"pr_{col}"] = df[col].rank(pct=True, method="average") * 100

w = {"fund_inflow_strength":0.4,"net_inflow_days":0.3,"fund_accel":0.2,"elg_net_ratio":0.1}
num = sum(df[f"pr_{c}"]*w[c] for c in w if df[c].notna().any())
den = sum(w[c] for c in w if df.loc[df.industry_code==BOARD, c].notna().all())
row = df[df.industry_code==BOARD].iloc[0]
score_fund = round(sum(row[f"pr_{c}"]*w[c] for c in w if pd.notna(row[c])) / den, 2)
print("calc score_fund", score_fund)
# 与 SELECT score_fund FROM dws_dc_industry_mainline_score_di ... 对比，差 ≤ 0.5
```

**通过标准**：抽测 2 个板块的 `score_fund`…`score_diffusion`、`total_score` 与库内差 ≤ **0.5**（四舍五入误差）。

## 11. 常见问题对照

| 现象 | 核查 SQL / 动作 |
|------|-----------------|
| DWS 行数为 0 | 先查 `dwm_dc_industry_fund_flow_di`；评分脚本在 fund 为空时会 skip |
| 五维 DWM 行数不一致 | 对比各维 `industry_code` 差集；多为 `ods_dc_member_di` 不全 |
| `score_prosperity` 全 NULL | 查 `ods_fina_indicator`、`ods_report_rc_di`；跑 `run_dwm_dc_industry_prosperity` 日志 |
| `score_heat` / 扩散偏低 | 查 `ods_limit_list_di`、`ods_dc_daily_di.amount`；跑 `run_dwm_market_breadth` |
| Web 五维页 500 | 查 `app_user` 是否已 GRANT 对应 `dwm_dc_*` 表 |
| 总分与手工差 > 1 | 确认 PERCENT_RANK 分区为 `trade_date + content_type`；缺失维是否降权 |
| 阶段全是「观察」 | 查 `fund_accel`、`net_inflow_days`、`limit_up_ratio` 是否达 §5.4 阈值 |
| 监控 `main_score` 与页面预期不符 | 默认取 `total_score_ma5`，历史不足 5 日时回退 `total_score` |
