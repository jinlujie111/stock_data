## 5. 个股因子正确性（P1）

### 5.1 量比手工验算（个股抽测 B）

```sql
SET @T = '2026-06-30';
SET @CODE = '600745.SH';  -- 替换为实际抽测代码

WITH hist AS (
  SELECT trade_date, vol
  FROM ods_stock_detail_di
  WHERE ts_code = @CODE
    AND trade_date <= @T
  ORDER BY trade_date DESC
  LIMIT 20
)
SELECT
  d.vol AS vol_today,
  (SELECT AVG(vol) FROM hist) AS vol_ma20_manual,
  d.vol / NULLIF((SELECT AVG(vol) FROM hist), 0) AS vol_ratio_manual,
  f.vol_ratio_20 AS vol_ratio_etl
FROM ods_stock_detail_di d
LEFT JOIN dwm_stock_vp_factor_di f
  ON f.trade_date = d.trade_date AND f.ts_code = d.ts_code AND f.vp_window = 20
WHERE d.trade_date = @T AND d.ts_code = @CODE;
-- 预期：vol_ratio_manual 与 vol_ratio_etl 误差 < 0.01
```

### 5.2 量价配合分类

对同一 `@CODE`：

| 检查项 | 方法 | 预期 |
|--------|------|------|
| pattern 与涨跌/量方向一致 | 读 `pct_chg`、`vol`、`vol_ma20` | 符合需求文档 §3.2(2) 四象限 |
| vp_pattern_score 范围 | SQL | 0 ≤ score ≤ 100 |
| trend_confirm 时 score | — | 通常 ≥ 80 |

### 5.3 突破标记

```sql
-- 若 is_breakout_60=1，则 close 应等于近 60 日最高，且 vol > 1.5*vol_ma20
SELECT ts_code, is_breakout_60, close, vol, vol_ma20
FROM dwm_stock_vp_factor_di
WHERE trade_date = @T AND vp_window = 20 AND is_breakout_60 = 1
LIMIT 5;
-- 手工核对 1~2 条
```

## 6. 行业聚合与评分（P1）

### 6.1 上涨家数占比

```sql
SET @T = '2026-06-30';
SET @BOARD = 'BK1036.DC';  -- 半导体

-- 手工：成分股 pct_chg>0 占比
SELECT
  SUM(CASE WHEN d.pct_chg > 0 THEN 1 ELSE 0 END) / COUNT(*) AS rising_manual,
  a.rising_ratio AS rising_etl
FROM ods_dc_member_di m
JOIN ods_stock_detail_di d ON d.trade_date = @T AND d.ts_code = m.con_code
JOIN dwm_industry_vp_agg_di a
  ON a.trade_date = @T AND a.industry_code = m.ts_code AND a.vp_window = 20
WHERE m.trade_date = (
  SELECT MAX(trade_date) FROM ods_dc_member_di
  WHERE trade_date <= @T AND ts_code = @BOARD
)
AND m.ts_code = @BOARD;
-- 预期：rising_manual ≈ rising_etl（误差 < 0.02）
```

### 6.2 VP Score 权重

从 `dwm_industry_vp_score_di` 取一条：

```text
vp_score ≈ 0.30*score_vol + 0.25*score_trend + 0.15*score_continuity
         + 0.15*score_breadth + 0.15*score_breakout
```

允许四舍五入误差 ±0.5 分。

### 6.3 状态分级

| vp_score | 预期 vp_status |
|----------|----------------|
| 85 | mainline_burst |
| 70 | trend_up |
| 50 | range_bound |
| 30 | weak |
| 10 | ebbing |

可对边界值 ±1 分各测一条。
